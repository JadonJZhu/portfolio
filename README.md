# Portfolio

My visual, game-like portfolio proposing a "prototype engineer" role at Riot Games. 

Live: https://jadonjzhu.github.io/portfolio/

## How to run it

You need Node 22.

```
node scripts/serve.mjs
```

Then open http://localhost:8000. The site is plain HTML, CSS and JavaScript with GSAP for the camera, so there is no build step. With JavaScript off or reduced motion on, it shows as an ordinary page you scroll.
